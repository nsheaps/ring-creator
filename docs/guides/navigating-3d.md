# Navigating the 3D view

Every ring, band and component preview in Ring Creator is a live 3D scene. In these guides the scenes load when you scroll to them, so try the one below.

::design{head=halo-round shank=tapered metal=platinum view=set caption="Try every control on this ring"}

## Mouse

- **Rotate:** drag with the left button.
- **Pan:** drag with the right button (or hold Shift and drag).
- **Zoom:** scroll the wheel. The view zooms toward the point under the cursor, so you can dive straight into the prongs.
- **Focus:** double-click any point to centre it and move in close.

## Touch

- **Rotate:** drag with one finger.
- **Pan and zoom:** drag with two fingers to pan, and pinch to zoom.
- **Focus:** double-tap a point.

## Keyboard

Click the view once so it has focus, then use the arrow keys to rotate. Page tabbing reaches the **Focus stone** and **Reset** buttons.

## Buttons

- **Focus stone** frames the centre stone close up.
- **Reset** returns to the default angle and distance.
- **Open in builder** (under guide previews) copies the previewed ring into the builder so you can change it.

## If a view stays a picture

Guide pages keep at most four live scenes running at once to protect your graphics card, so scenes far off screen go back to a still picture until you scroll to them again. Select a still picture or its **Spin it** label to wake it. If nothing ever loads, see [Troubleshooting](#/docs/troubleshooting).
